# 问卷算法设计

## 文档目的

- 按 `问卷.json` 的原始顺序展开题目，改写为便于人工审阅的文档形式。
- 对每道题做算法归类：
  - 匹配型：双方答案越接近，得分越高。
  - 互补型：不是看“像不像”，而是看“方向是否咬合”。
- 对每道题标记是否需要调用用户基本信息。
- 文档先给出当前版本的计算框架，后续再继续细化特殊题规则。

## 当前可直接调用的用户基本信息

- `birth_year`
- `grade`
- `gender`
- `department`
- `campus`

## 前置硬规则

以下规则不参与问卷逐题计分，而是在进入问卷算法前先做配对排除。只要不满足，即直接判定该配对无效，不进入后续题目计算。

1. 必须为异性
   - 使用字段：`gender`
   - 规则说明：双方性别必须不同，否则直接排除。

2. 必须同校区
   - 使用字段：`campus`
   - 规则说明：双方校区必须一致，否则直接排除。

## 计分方式

### 总体流程

1. 先执行前置硬规则。
2. 通过前置硬规则后，再进入问卷逐题计分。
3. 每题先计算出 `0 ~ 1` 的原始分数。
4. 再按题目权重参与总分汇总。
5. 最终总分继续沿用当前系统的汇总方式。

### 匹配型题目

匹配型题目继续沿用当前实现，不改算法类型，只允许后续按需要调整权重。

1. 单选题
   - 继续按原有算法。
   - 双方答案相同则得 `1` 分，不同则得 `0` 分。

2. 多选题
   - 继续按原有算法。
   - 使用双方选项集合的交并比计算：
   - `score = 共同选项数 / 去重后总选项数`

3. Scale 题
   - 继续按原有算法。
   - 按双方答案距离计算，距离越近得分越高。
   - 通用形式：
   - `score = 1 - |a - b| / range`
   - 当量表范围是 `1 ~ 7` 时：
   - `score = 1 - |a - b| / 6`

### 互补型题目

互补型题目不看双方是否接近，而是看双方在同一条轴上的位置是否互相咬合。

- 适用场景：
  - 一方偏左、一方偏右，且两者正好形成互补。
  - 中间值与中间值也可以形成较高适配。

- 当 scale 范围是 `1 ~ 7` 时，使用公式：
  - `score = 1 - |(a + b) - 8| / 6`

- 公式说明：
  - `a` 和 `b` 分别是双方在该题上的作答，取值范围均为 `1 ~ 7`。
  - 当 `a + b = 8` 时，得分最高，为 `1`。
  - 当双方明显处于同一侧且不互补时，得分下降。

### 特殊算法题目

少数题目不能只根据题型决定得分，需要按 `questionCode` 单独写分支，优先级高于通用算法。

1. 当前特殊题
   - `q-age-preference`

2. 通用执行顺序
   - 先识别该题是否属于特殊题。
   - 若是特殊题，则直接进入该题专用算法。
   - 若不是特殊题，则继续按“匹配型单选 / 多选 / scale”的原有算法处理。

3. `q-age-preference` 可执行算法
   - 当前需要调用的用户基本信息：
   - `birth_year`
   - 双方答案取值：
   - `older` = 偏爱年上
   - `same-age` = 偏爱同岁
   - `younger` = 偏爱年下
   - `soul-match` = 年龄不卡死

4. `q-age-preference` 计算步骤
   - 设左侧用户为 `L`，右侧用户为 `R`。
   - 使用出生年份判断双方真实年龄关系：
   - 若 `L.birth_year > R.birth_year`，则 `L` 更年轻，`R` 更年长。
   - 若 `L.birth_year = R.birth_year`，则双方同岁。
   - 若 `L.birth_year < R.birth_year`，则 `L` 更年长，`R` 更年轻。

5. 单侧满意度函数
   - 先分别计算左侧用户对右侧用户的满意度 `sL`，以及右侧用户对左侧用户的满意度 `sR`。
   - 单侧满意度取值范围为 `0 ~ 1`。

6. 单侧满意度计算规则
   - 若用户选择 `older`：
   - 对方比自己年长，则该侧满意度 = `1`
   - 对方与自己同岁，则该侧满意度 = `0.25`
   - 对方比自己年轻，则该侧满意度 = `0`

   - 若用户选择 `same-age`：
   - 双方同岁，则该侧满意度 = `1`
   - 双方相差 `1` 岁，则该侧满意度 = `0.5`
   - 双方相差 `2` 岁及以上，则该侧满意度 = `0`

   - 若用户选择 `younger`：
   - 对方比自己年轻，则该侧满意度 = `1`
   - 对方与自己同岁，则该侧满意度 = `0.25`
   - 对方比自己年长，则该侧满意度 = `0`

   - 若用户选择 `soul-match`：
   - 该侧满意度 = `1`

7. 最终题目得分
   - `score = sL × sR`

8. 公式说明
   - 只有双方都满足各自年龄偏好时，本题才会拿到高分。
   - 若只有一方满意、另一方不满意，则最终得分会明显下降。
   - 若一方选择 `soul-match`，则该侧不对年龄方向施加限制，最终得分主要由另一侧偏好决定。

9. 示例
   - 女方选择 `older`，男方选择 `younger`，且女方实际比男方年轻：
   - `sL = 1`，`sR = 1`，最终 `score = 1`

   - 女方选择 `older`，男方也选择 `older`，且女方实际比男方年轻：
   - 女方满意，男方不满意
   - `sL = 1`，`sR = 0`，最终 `score = 0`

   - 双方都选择 `same-age`，且相差 1 岁：
   - `sL = 0.5`，`sR = 0.5`，最终 `score = 0.25`
